## Reviewer Gate

Accept progress only if it is one of:

- a compiled local Lean declaration in a reusable module;
- a source-indexed proof obligation with exact hidden regularity;
- an external reference audit that identifies concrete Mathlib/API names and
  a port plan;
- a documented rejection of a false or source-unsupported statement.

Reject progress if it is:

- SALD-specific wrapper churn;
- a theorem status promotion without `python3 tools/astis.py check`;
- an assumption added only to make Lean close;
- an external theorem treated as callable without a local compiled declaration.
