# Samplinglib Libraries

This directory records the source maps, owners, upstream formal libraries, and truth boundaries for the four first-class Samplinglib libraries.

| Library | Source | Owners | Current status |
|---|---|---|---|
| Log-Concave Sampling | Sinho Chewi | Dake, Ji | active |
| SampleWiki | source-pinned frontier papers | Dake, Ji | active |
| Riemannian Optimization | Nicolas Boumal | Andi, Dake | chapter scaffold |
| First-Order Optimization | Amir Beck + Optlib + CvxLean | Dake, Huanjian, Andi | chapter scaffold |

A scaffold establishes stable chapter URLs, source boundaries, ownership, and the future graph location. It does not certify any theorem.

Upstream code is not copied blindly. Each candidate node is classified as `reuse`, `adapt`, `missing`, or `out_of_scope`, with exact provenance and toolchain compatibility recorded.
