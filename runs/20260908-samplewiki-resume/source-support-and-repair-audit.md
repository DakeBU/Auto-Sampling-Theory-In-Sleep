## Positive support is part of the source convention

Section 1.1 defines the state space as the positive-probability configurations
inside the Boolean cube. Section 1.3 starts its update in that state space.
Thus the source supplies positive starting-atom mass, not merely membership in
an arbitrary subset. Represent the target on the ambient finite Boolean cube
and the source-valid start by `mu {x} != 0`. Each retained fiber contains `x`, so

\[
 0<\mu(\{x\})\leq\mu(F_i(x))\leq1.
\]

No extra positivity premise or source repair is needed for this denominator.
`Fin (n+1)` makes explicit the nonempty site set required for uniform selection.
The clock is one update, not one sweep. The consumer specializes the shared
finite-measure theorem to a finite Boolean probability target. Its ambient
kernel may be totalized, but unsupported starting points are outside the
source algorithm's claimed domain.
